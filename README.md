## ⚡ Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

- **Assets:** WebP image optimization & WCAG 2.2 AA accessibility standards
